# File Organizer

Organiza arquivos de uma pasta em subpastas ( Imagens, Vídeos, Áudio, Documents, Others)

## Como Usar

python organizer.py 

## O que aprendi 
- pathlib para manipulação de caminhos
- shutil para mover arquivos
- dicionários para mapear extensões a categorias 
- iterdir para listar arquivos
